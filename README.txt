THE FOUNDRY AMAZON - RETURNS SORT STATION
========================================

HOW TO RUN
1. Extract this ZIP.
2. Open the enclosed index.html file in Chrome, Safari or Edge.
3. Best viewed on an iPad in landscape. No scrolling is needed.

HOW IT WORKS
- The left panel displays a location from A-1 to E-5.
- One of the nine grey totes on the blue shelving glows green.
- Learners scan parcels externally using the real handheld barcode scanners; this app does not scan.
- Press the large green NEXT button to show the next location and destination.
- There are 25 locations in each shift, in a mixed sequence.
- Progress is stored locally where the browser allows it. Replacing these files does not delete saved progress.
- Press the circular-arrow button to restart a shift (confirmation required).

FULL SCREEN ON IPAD
- Press FULL SCREEN in the top right. Where the browser supports the Fullscreen API this enters/exits full screen.
- Some versions of Safari on iPad block full-screen mode for regular webpages.
- In that case, open the hosted app in Safari, tap Share > Add to Home Screen, then launch from the icon.
- The standalone-capable metadata is included for supported iPads.

WHAT IS INCLUDED
index.html: The complete offline HTML app
assets/amazon-returns.png: The supplied training logo
assets/tote.png: Symmetrical front-facing tote artwork from the approved first design, with transparency
print-labels.html: Printable practice barcode sheet from the previous build
